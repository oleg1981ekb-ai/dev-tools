# PDF ↔ Excel Compare

Сравнение таблицы Excel с таблицами из PDF. Утилита читает все страницы PDF,
склеивает таблицы, сопоставляет колонки и строки и сохраняет расхождения в
Excel-отчёт.

## Возможности

- чтение всех страниц PDF через `pdfplumber`;
- отбрасывание повторяющейся шапки на последующих страницах;
- пропуск пустых строк, выравнивание «рваных» строк;
- сопоставление колонок: точное → нечёткое → позиционное;
- позиционное сравнение строк (по порядку);
- числа сравниваются через `Decimal` с абсолютным и относительным допуском;
- текст сравнивается без учёта регистра, лишних пробелов и «ё»;
- отчёт из нескольких листов с сохранением исходных значений.

## Установка

```bash
cd PDF_Excel_compare
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Положите `source.xlsx` и `printed.pdf` в папку проекта и выполните:

```bash
python main.py
```

Или укажите пути явно:

```bash
python main.py \
  --excel source.xlsx \
  --pdf printed.pdf \
  --report differences_report.xlsx
```

Параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--excel` | `source.xlsx` | файл Excel (эталон) |
| `--pdf` | `printed.pdf` | PDF с таблицами |
| `--report` | `differences_report.xlsx` | файл отчёта |
| `--sheet` | `0` | индекс или имя листа Excel |
| `--abs-tolerance` | `1e-9` | абсолютный допуск для чисел |
| `--rel-tolerance` | `1e-6` | относительный допуск для чисел |

Код возврата: `0` — сравнение выполнено (даже если есть расхождения),
`1` — ошибка входных данных или чтения.

## Правила сравнения

- Сравниваются все заполненные ячейки: если обе пустые — различия нет.
- Строки сопоставляются по порядку. Если строк больше в одном файле, лишние
  попадают в отчёт как «Нет строки».
- Колонки сначала сопоставляются по нормализованным заголовкам, затем нечётко,
  затем позиционно. Несопоставленные колонки попадают в отчёт.
- Числа: `1 234,56` = `1234.560`, `1.0` = `1`; допуск настраивается.
- Текст: регистр, повторные пробелы и «ё/е» не считаются различием.
- Смешанные значения (`12 шт`, проценты) сравниваются как текст.

## Отчёт

| Лист | Содержимое |
|---|---|
| `Summary` | параметры сравнения, количество строк/колонок, статистика, вердикт |
| `Differences` | все расхождения: строки, колонки, исходные значения, тип |
| `Columns` | какие колонки сопоставлены и каким методом |
| `Only in Excel` | строки и колонки, которых нет в PDF |
| `Only in PDF` | строки и колонки, которых нет в Excel |

## Ограничения

- Сканированный PDF без текстового слоя не поддерживается.
- Сложные объединённые ячейки и многострочные шапки могут извлекаться неточно.
- Сравнение позиционное: вставка или удаление строки в середине сдвигает
  последующие строки и даёт «каскад» расхождений.
- Поддерживается один лист Excel за запуск.

## Планы

- формат ГрандСметы: отдельный reader, возвращающий ту же модель `TableData`;
- режим сопоставления строк по ключевым колонкам;
- проверка на реальных PDF объёмом до 50 страниц.
