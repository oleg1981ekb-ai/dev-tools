# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased]

### Added

- CLI-сравнение таблицы Excel с таблицами из PDF.
- Извлечение всех страниц PDF, отбрасывание повторной шапки, выравнивание
  рваных строк.
- Сопоставление колонок (exact → fuzzy → positional) и позиционное сравнение
  строк.
- Сравнение чисел через `Decimal` с абсолютным и относительным допуском.
- Excel-отчёт: `Summary`, `Differences`, `Columns`, `Only in Excel`,
  `Only in PDF`.
- Тесты pytest и CI с фильтром `paths`.
- **Улучшен UI отчёта**: цветовое кодирование типов различий, условное форматирование,
  стилизация header по цвету для каждого листа, DataBar для оценки сходства колонок.

### Changed

- PDF-ридер: поддержка многострочной шапки, отбрасывание строки документа
  (гигантская объединённая ячейка) и строки нумерации колонок (1..N).
- PDF-ридер: обрезка строк подписей в конце документа (как в Excel).
- Сравнение: строки «Итого» с одной меткой и одной суммой в разных колонках
  теперь считаются совпадением (игнорирует смещение колонок при экспорте).
- **UI отчёта differences_report.xlsx**: улучшена наглядность с цветовым кодированием,
  цветовыми шапками листов,DataBar и условным форматированием.

### Changed

- **OCR fallback**: добавлен флаг `--ocr` (none/paddle/full, по умолчанию `none`).
  При включении (`--ocr full`) пустые ячейки pdfplumber заполняются текстом,
  распознанным через Tesseract OCR (поддерживается язык rus+eng).
  Результат сохраняется в `ComparisonResult` с полями `source`, `ocr_confidence`,
  `is_handwritten`.
