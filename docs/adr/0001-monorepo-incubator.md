# ADR-0001: Монорепо «инкубатор → продукт»

Дата: 2026-10-17
Статус: принято

## Контекст

У одного разработчика несколько мелких утилит (генератор графиков Ганта,
расчёт сметы по PDF, извлечение таблиц из PDF). Встал вопрос: один общий
репозиторий или отдельный под каждый проект.

## Решение

Проекты живут в монорепо `dev-tools` («инкубатор»), пока не созреют для
отдельного репозитория. Критерии готовности — в README, раздел
«Стратегия развития»: свой README + тесты и CI, второй разработчик или
внешний пользователь, юридические границы (NDA/лицензия).

Порядок выделения: `gh repo create` → перенос папки → `git rm -r <папка>`
→ ссылка в README инкубатора.

## Последствия

+ Нулевые накладные расходы на старте (один CI, один clone, общие правила).
+ Проекты не мешают друг другу, пока изолированы по папкам.
− Связывание несвязанного: CI одного проекта срабатывал на правки другого.
  Частично закрыто фильтром `paths:` в workflow (см. ADR про CI при появлении).
− При выделении понадобится перенос истории (`git filter-repo`) либо
  чистый старт (допустимо для PoC).
