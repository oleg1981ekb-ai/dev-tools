# BIM Estimate AI

Прототип (PoC) инструмента для автоматического расчёта сметы на кладку наружных стен
по архитектурному чертежу в формате PDF. Извлекает геометрию из текстового слоя PDF
и считает объёмы газосиликатных блоков (200 мм) с запасом на подрезку и бой.

## Возможности

- **AI-путь** (`main.py` → `object_detection.py`): текстовый слой PDF отправляется
  в LLM (Groq / Qwen), которая выполняет инженерный анализ и возвращает готовую ведомость.
- **Детерминированный путь** (`extract_walls.py`): парсинг типовых размеров регулярными
  выражениями и расчёт объёмов по формуле `длина × толщина × высота × 1.05`.

Результат сохраняется в CSV-ведомость (`data/estimated_materials.csv`).

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка (только для AI-пути)

Получите API-ключ на [console.groq.com](https://console.groq.com) и задайте его
как переменную окружения (файл `.env` в git не попадает):

```bash
export GROQ_API_KEY=ваш_ключ
```

## Запуск

Положите свой PDF-чертёж в `case_01_block_takeoff/data/` (путь захардкожен в скриптах,
при необходимости поправьте его в начале файлов).

```bash
# AI-расчёт через LLM
python case_01_block_takeoff/main.py

# Детерминированный расчёт (интерактивно спрашивает высоту стен)
python case_01_block_takeoff/extract_walls.py
```

## Структура

```
case_01_block_takeoff/
├── main.py               # точка входа AI-пути
├── object_detection.py   # извлечение текста PDF → запрос в Groq → CSV
├── extract_walls.py      # детерминированный расчёт по regex-поиску размеров
└── data/                 # PDF-чертежи (не коммитятся) и выходные CSV
```

## Ограничения

- Проект находится на стадии PoC: правила поиска размеров заточены под конкретный
  тип чертежа (кладочный план АР).
- Качество AI-расчёта зависит от того, насколько точно LLM разберёт текстовый слой PDF.
- Абсолютные пути в скриптах прописаны под macOS-окружение автора.

## Требования

- Python 3.10+
- Зависимости: PyMuPDF, pandas, groq (см. `requirements.txt`)
