# ADR-0004: Каталог конструкций — разделы, послойный парсинг, счётные слои

Дата: 2026-10-17
Статус: принято

## Контекст

Экспликация на листе чертежа разбита на РАЗДЕЛЫ: «Наружная стена», «Внутренние стены», «Перегородки», «Зашивки». Нумерация типов внутри разделов независимая: «Наружная стена Тип 1» ≠ «Перегородка Тип 1». Раньше парсер искал «Тип N» по всему тексту без привязки к разделу, что приводило к смешиванию типов из разных разделов.

Кроме того, при извлечении текстового слоя PDF пункты собственно внутренних стен (кирпич, газоблок) идут ДО заголовка «Внутренние стены:» (порядок чтения текстового слоя не соответствует визуальному). pending-аккумулятор приписывает эти слои Типу 2 наружных стен, и кирпич/газоблок теряются как отдельные позиции.

## Решение

1. **Парсинг по разделам.** Заголовки разделов определяются через `_is_section_header()` — только короткие строки без «мм» («Перегородки:», «Внутренние стены:», «Наружная стена Тип 1:»). Слой с «мм» («- перегородки из кирпича ... 250 мм») не принимается за заголовок, иначе обрезался Тип 2.

2. **ID с разделом.** Запись каталога: `{id: «Раздел|Тип N», section, type_no, ...}`. Разные разделы с одинаковым номером типа — разные id («Наружная стена|Тип 1» ≠ «Перегородка|Тип 1»).

3. **Послойный парсинг.** Описание типа разбивается на слои через разделитель « | » (каждый буллит — отдельный слой пирога: фасад, утеплитель, монолит, кирпич, газоблок). Каждый слой: `{material, thickness_mm, countable}`. `thickness_mm=None` = толщина не отражена (монолит ЖБ без «мм» — штатно, объём не считается).

4. **Счётные слои.** Только газосиликат 200 мм (ГОСТ 31359) идёт в смету блоков. Монолит ЖБ — раздел КР, не считается (толщина может не отражаться в АР). Утеплитель, фасад, кирпич — не блоки. Двойная толщина кирпича (120/250) — не счётная в любом случае.

5. **Материал типа.** Берётся из первого счётного слоя; если счётных нет — из последнего слоя с толщиной. Монолит не попадает в материал (см. КР).

6. **Внутренние стены как отдельные позиции.** Кирпич и газоблок, прилипшие к Типу 2, отщепляются функцией `_fixup_outer_type2()` и становятся позициями «Внутренняя стена|N». Срабатывает только если раздел «Внутренние стены» уже есть в каталоге. Буллиты под заголовком «Внутренние стены:» без «Тип N» создают позиции непосредственно.

## Последствия

- Каталог теперь содержит 10 позиций для образцового чертежа (было 7): 2 наружные стены + 3 внутренние стены + 5 перегородок.
- Внутренняя стена с газоблоком 200 — счётная позиция для расчёта блоков.
- Монолитные слои имеют `thickness_mm=None`, не участвуют в объёмных расчётах.
- Маркеры «Тип N» на плане распределяются по id каталога через `markers_by_catalog_id()`; при неоднозначном номере типа (в нескольких разделах) счётчик делится с пометкой «?».
- Политика слияния в main — squash merge (ADR-0002).
