# Dev Tools Monorepo 🛠

Коллекция автоматизированных утилит и скриптов для оптимизации рабочих процессов.
Это **инкубатор**: небольшие проекты живут здесь до тех пор, пока не «вызреют»
до отдельного репозитория (см. [Стратегию](#-стратегия-развития)).

## 📂 Структура репозитория

### Продукты

- `gantt-generator/` — Генератор профессиональных строительных графиков и диаграмм Ганта в Excel (`.xlsx`) с поддержкой внешнего `tasks.json` и компактного календаря.
  - CI собирает Windows EXE (PyInstaller) при изменении файлов этой папки — [.github/workflows/build.yml](.github/workflows/build.yml).
  - Запуск: `python gantt-generator/main.py`.

### В разработке (PoC)

- `bim-estimate-ai/` — Прототип AI-расчёта сметы на кладку наружных стен по PDF-чертежу (АР): извлечение текстового слоя → анализ LLM (Groq) либо детерминированный regex-расчёт → CSV-ведомость.
  - Подробности в [bim-estimate-ai/README.md](bim-estimate-ai/README.md).
  - Требуется `GROQ_API_KEY` в переменных окружения (файл `.env` в git не попадает).

### Общие утилиты

- `pdf-table-extractor/` — Извлечение таблиц из PDF в Excel через `camelot` (по линиям сетки). Читает файл из `~/Downloads`, сохраняет `.xlsx` на Рабочий стол.

### Новые проекты

- `PDF_Excel_compare/` — Сравнение таблицы Excel с таблицами из PDF: извлечение всех страниц, сопоставление колонок и строк, Excel-отчёт с расхождениями.
  - Подробности в [PDF_Excel_compare/README.md](PDF_Excel_compare/README.md).

## 🛠 Общие конвенции

- Секреты — только в `.env`, который исключён через `.gitignore`. **Никогда** не коммитить ключи и клиентские PDF.
- Один коммит — одна тема (не смешивать уборку, рефакторинг и функциональные правки).
- Ветки: `main` — стабильное состояние; фичи — в `feature/*`, затем PR в `main`.

## 🚀 Стратегия развития

Принцип **«инкубатор → продукт»**: проект живёт в `dev-tools`, пока не готов
к самостоятельной жизни.

**Признаки готовности к выделению в отдельный репозиторий:**

1. Свой README с установкой, скриншотами, версионированием (semver/релизы).
2. Тесты и CI, запускаемые независимо от других папок.
3. Второй разработчик или внешний пользователь.
4. Юридические границы (клиентский код, NDA, лицензия).

**Порядок выделения:**

```bash
gh repo create oleg1981ekb-ai/<имя-проекта> --private
# перенос папки (с историей через git filter-repo или начисто для PoC)
git rm -r <папка>          # убрать из dev-tools
# в README оставить ссылку: «→ вынесено в отдельный репозиторий»
```

**Сейчас к выделению готов** `gantt-generator` (есть CI и релизы).
**Остаётся в инкубаторе** `bim-estimate-ai` (стадия PoC).
