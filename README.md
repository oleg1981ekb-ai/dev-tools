# Dev Tools Monorepo 🛠

Коллекция автоматизированных утилит и скриптов для оптимизации рабочих процессов.

## 📂 Структура репозитория

- `gantt-generator/` — Генератор профессиональных строительных графиков и диаграмм Ганта в Excel (`.xlsx`) с поддержкой внешнего `tasks.json` и компактного календаря.
